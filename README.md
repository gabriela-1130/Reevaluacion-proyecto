# Reevaluacion-proyecto
# Refugio de Perros y Gatos

Este proyecto modela un refugio donde se registran animales, voluntarios y adopciones.

## ¿Para qué sirve este programa?
- Para crear objetos de tipo Animal, Voluntario y Adopción.
- Para probar métodos básicos y demostrar encapsulamiento.
- Para representar de forma simple cómo funciona un refugio.

## ¿Para qué NO sirve este programa?
- No relaciona con bases de datos reales.
- No registra adopciones reales.
- No maneja interfaz gráfica.
- No incluye todavía herencia, composición o validaciones avanzadas (se agregará en avances posteriores).

## ¿Cómo se usa?
Solo se ejecuta y el programa:
1. Crea un perro, un gato, un voluntario y una adopción.
2. Llama sus métodos para comprobar que funcionan.
3. Muestra datos usando getters y setters.
